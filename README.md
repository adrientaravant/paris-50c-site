# Paris à 50°C — editable site copy

Recovered from the live deployment at https://paris-50c.vercel.app/ on 27 September 2026.

- Edit `index.html` for text, layout, styles, and behavior. The CSS and JavaScript are embedded in this file.
- Images are in `assets/illustrations/`.
- To preview locally, run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.
- Deploy this directory as a static site from your own Vercel account or another static host.

This is a copy of the deployed public website. It does not include the original local project history, Vercel account access, or historical analytics.
