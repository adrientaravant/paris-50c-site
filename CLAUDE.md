# Project instructions

This repository contains an editable copy of the deployed Paris à 50°C static website.

- Keep the site in `index.html`, with images in `assets/illustrations/`.
- Preview from the repository root with `python3 -m http.server 8000`.
- Before publishing, verify that every local asset referenced by `index.html` exists and check the page visually.
- Do not commit secrets, local account files, or deployment configuration downloaded from Vercel.
